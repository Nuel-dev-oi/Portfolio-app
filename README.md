# Okoro Emmanuel Onyedikachi — Portfolio

Personal portfolio website for Okoro Emmanuel Onyedikachi, Full-Stack & Frontend Engineer based in Lagos, Nigeria.

**Live site:** https://portfolio-app-client-delta.vercel.app

## Stack

- **Frontend:** React 19, TypeScript, Vite 5, Tailwind CSS v4, GSAP 3
- **Backend:** Node.js, Express, MongoDB Atlas, Nodemailer
- **Deployment:** Vercel (client + server)

## Features

- Animated hero with GSAP letter-by-letter name reveal
- Interactive node graph canvas background
- Multilingual support (English / French)
- Dark / light mode
- Contact form with email notifications via Nodemailer
- Floating chat widget with WhatsApp and email shortcuts
- Fully responsive (mobile-first)

## Project Structure

```
Portfolio_App/
├── client/          # React frontend (Vite)
└── server/          # Express backend (Vercel serverless)
```

## Local Development

```bash
# Install dependencies
npm install

# Run frontend
cd client && npm run dev

# Run backend
cd server && npm run dev
```
